# Silverline Station Hub

A TanStack Start + Vite application for security operations workflows.

## Local development

1. Install dependencies with `npm install`
2. Create a `.env` file with:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`
3. Run `npm run dev`

## Deploy to GitHub Pages

This repository includes a GitHub Actions workflow that publishes the built app to GitHub Pages.

1. Enable GitHub Pages in the repository settings.
2. Set the source to GitHub Actions.
3. Push to the `main` branch or run the workflow manually.
